What you need

Minimum requirement: A Gene ID or gene annotation keywords (based on BLASTP homology searches against rice/Arabidopsis proteins).

Gene ID

Enter a gene identifier such as dpcaXXXX. You can input multiple Gene IDs separated by spaces or commas.

Annotation keywords

Type keywords (e.g., a protein name). Genes whose homology-based annotations (from rice/Arabidopsis BLASTP searches) contain the keyword will be listed and plotted (up to 500 genes).

Page layout

Control panel (top)

Choose Reference genome cultivar, input Gene ID or annotation, set Group by, and configure options such as Use regex, Convert to log10(TPM + 1), and the sample keyword filter.

Plot area (middle)

Expression is shown as an interactive Plotly violin plot. Use the Plotly toolbar (zoom/pan/reset/download as PNG) directly on the figure.

Data table (bottom)

The table shows the sample metadata and the expression value (TPM, and optionally log-transformed). Clicking a point in the plot highlights the corresponding row.

Similarity panel (Pearl millet)

For Pearl millet, when the reference genome cultivar is set, a panel lists high-similarity genes in other cultivars and lets you open their expression plots.

Step-by-step workflow

  1. Open a crop page. For example, go to the Pearl millet page. (Other crops are available from the Home page.)
  2. Select the reference genome cultivar using the Reference genome cultivar dropdown. The page will automatically move to the corresponding dataset/page.
  3. Enter a Gene ID or annotation keywords in the input box. If you type a Gene ID, autocomplete suggestions may appear.
  4. (Optional) Use regex for Gene ID search. Check Use regex (Gene ID search) or input a regex using /.../flags (e.g., /^dpca1g000*.840/i).
  5. Choose the grouping variable with Group by (e.g., tissue, treatment, stage, cultivar, or Show all samples (not grouping)).
  6. Set optional display options such as Convert to log10(TPM + 1).
  7. Click Generate plot. The plot and table will update.
  8. Explore interactively. Hover points for metadata and expression; zoom/pan using the Plotly toolbar.

Multi-gene and annotation search

Multiple Gene IDs: you can enter multiple IDs separated by spaces or commas (e.g., dpcaXXXX dpcaYYYY). Each gene will be plotted.

Annotation keywords: when you search by annotation, the page finds genes whose annotation text contains all provided keywords (AND search), lists them under Matched genes, and plots them together (up to 500 genes).

Filters and transformations

Log transform

Enable Convert to log10(TPM + 1) to reduce the effect of highly expressed outliers. Both the plot axis and the data table will reflect this choice.

Keyword filter for samples

Enable Enable keyword filter for samples, then type keywords into Search key words. Samples are kept only if their metadata contains all keywords (AND search; space-separated). Press Enter to redraw the plot.

Data table and point selection

The table section (Data used for the plot) shows the metadata and expression values used in the current plot. When multiple genes are plotted, choose the gene displayed in the table using Gene for table.

Tip: Click any point in the plot to highlight the corresponding table row.

High-similarity genes in other cultivars (Pearl millet)

On the Pearl millet page, when the reference genome cultivar is set, the High sequence similarity genes in other cultivars panel appears. After plotting a gene, you can pick the base gene (if multiple genes are plotted) and the panel lists corresponding high-similarity genes in other cultivars. Clicking a listed gene to plot it.

Troubleshooting

  • “Now loading…” stays for a long time: please reload the page. Large datasets may take time to fetch on the first access.
  • No matched genes: confirm the Gene ID format, or try fewer/more general annotation keywords.
  • Annotation search does not work: annotation file may not be available for that crop; try Gene ID search instead.
  • Nothing changes after keywords: after enabling the keyword filter, press Enter or click Generate plot again.
For downloadable files (TPM matrices, gene counts, annotations), please visit the Download page.
Example of use

How GExA can be used to query genes, visualize expression profiles, inspect sample-level metadata, and compare candidate genes identified by homology-based annotation search.

Example 1. Querying a pearl millet gene by Gene ID

This example examines the pearl millet gene dpca1g022930.840. It is the closest homolog of rice HVA22 (LOC_Os11g30500), and it has been reported as a dehydration- and abscisic acid (ABA)-responsive gene in pearl millet (Qazi et al., 2025).

  1. Open the pearl millet expression atlas by clicking Open pearl millet expression atlas on the Home page (Fig. 1A).
  2. Select the reference genome cultivar. Because dpca1g022930.840 is a Gene ID from the Tift genome, choose Tift as the reference genome cultivar (Fig. 1B).
  3. Enter dpca1g022930.840 in the Gene ID field. To examine whether the gene is induced under specific conditions, select treatment as the metadata category for grouping (Fig. 1C).
  4. Click the Generate plot button. An interactive plot is displayed in which the x-axis represents treatment categories and the y-axis represents expression level in TPM (Fig. 1C and 1D).
  5. Click the Gene ID above the plot to open TGIF-DB and view detailed information for the selected gene (Fig. 1E).
  6. Click a legend item to show or hide the corresponding category in the plot. For example, categories such as NA (unavailable or unassignable metadata) can be hidden when they are not relevant to the current comparison (Fig. 1D).
  7. Click an individual point in the plot to display the corresponding sample information in the table below the plot (Fig. 1F).

Example 2. Searching genes by annotation keyword

GExA can also be used when a specific Gene ID is not known. By entering an annotation keyword such as HVA22, users can identify genes whose homology-based annotations, derived from rice and/or Arabidopsis genes, contain the keyword. And then their expression profiles are visualized on the same page.

  1. Enter HVA22 in the annotation keyword field and click the Generate plot button (Fig. 2A).
  2. Pearl millet genes are listed whose homology-based annotations, inferred from rice and/or Arabidopsis genes, contain the keyword HVA22 in the associated annotation or gene name (Fig. 2A).
  3. The matched genes are plotted together on the same page, allowing users to compare their expression patterns across the selected metadata category (Fig. 2B).
