# GExA: Grass Expression Atlas

The source code for **GExA (Grass Expression Atlas, https://www.gexa.anesc.u-tokyo.ac.jp/)**, a web-based transcriptome database for exploring gene expression patterns in grass species.

## Contents

This repository includes the source files used to build and operate the GExA website, including:

* HTML, CSS, and JavaScript files
* Shard files used by the web application

Large data files, including expression matrices and annotation files, are not included in this repository.

## GExA

GExA provides an interactive interface for exploring publicly available RNA-seq datasets and gene expression profiles across multiple grass species.

Website: https://www.gexa.anesc.u-tokyo.ac.jp/

## Data

Datasets used in GExA are distributed separately from this source-code repository in https://www.gexa.anesc.u-tokyo.ac.jp/Download/ or https://doi.org/10.6084/m9.figshare.31669273.
